# 8. HOSTING & DEPLOYMENT

Website akan di-host menggunakan **GitHub Pages dengan tipe Project Site**.

URL yang direncanakan:

`https://USERNAME.github.io/siteworthy/`

Nama repository diasumsikan `siteworthy`, tetapi harus dikonfirmasi sebelum konfigurasi final.

Ketentuan wajib:

1. Website harus sepenuhnya kompatibel dengan GitHub Pages.
2. Website harus dapat di-deploy sebagai static website.
3. Tidak boleh membutuhkan backend server.
4. Jangan menggunakan database atau server-side functionality yang membutuhkan server aktif.
5. Semua asset harus menggunakan path yang kompatibel dengan GitHub Pages.
6. Perhatikan konfigurasi base path `/siteworthy/` jika menggunakan repository tersebut.
7. Hindari routing yang menyebabkan 404 ketika halaman di-refresh.
8. Pastikan hasil build memiliki index.html pada direktori deployment.
9. Siapkan deployment menggunakan GitHub Actions.
10. Website otomatis di-deploy ketika terdapat perubahan pada branch main.
11. Jangan menyimpan API key, password, token, atau informasi rahasia di repository.

Jangan mengasumsikan username GitHub. Buat konfigurasi yang mudah diperbarui.

1. Website berhasil dijalankan secara lokal.
2. Build berhasil tanpa error.

4. Tidak ada broken links.

7. Website berfungsi pada perangkat mobile.

Setelah deployment berhasil:
