# Siteworthy - Portfolio Website

> **"Your Business Deserves a Better Website."**  
> Siteworthy adalah freelance web development studio berbasis di Semarang, Indonesia yang berfokus membantu pelaku UMKM membangun kehadiran digital yang profesional, modern, dan mudah diakses.

---

## 📌 Ringkasan Proyek

Website ini adalah website satu halaman (*Single Page Website*) profesional yang dirancang khusus untuk membangun kredibilitas, memamerkan kapabilitas studio, serta memudahkan calon klien lokal menghubungi Siteworthy melalui jalur komunikasi langsung.

- **Klien / Target:** Pelaku UMKM di Semarang & sekitarnya
- **Model Hosting:** GitHub Pages (Project Site: `https://<USERNAME>.github.io/siteworthy/`)
- **Arsitektur:** Static Site (Vite + React + TypeScript + Tailwind CSS)
- **Dokumentasi Terkait:**
  - [PROJECT_BRIEF.md](PROJECT_BRIEF.md) - Brief lengkap proyek
  - [ARCHITECTURE.md](ARCHITECTURE.md) - Gambaran arsitektur sistem
  - [TASKS.md](TASKS.md) - Rincian tugas implementasi

---

## 🛠️ Tech Stack

- **Framework & Bundler:** React (TypeScript) + Vite
- **Styling:** Tailwind CSS
- **Icons:** Lucide React / SVG kustom
- **Deployment:** GitHub Actions -> GitHub Pages

---

## 🚀 Memulai Pengembangan Lokal

```bash
# Instal dependensi
npm install

# Jalankan development server
npm run dev

# Jalankan linting & format
npm run lint
npm run format

# Build untuk produksi
npm run build
```
